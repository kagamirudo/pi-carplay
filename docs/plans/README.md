# Plans

Design and implementation plans for pi-carplay. Each plan is one Markdown file, written before the work starts and kept afterwards as a record of what was decided and why.

## Convention

- **File name:** `NNNN-short-kebab-topic.md`. `NNNN` is the next free four-digit number. Numbers are never reused.
- **Header:** a small table at the top with the plan number, status, date (`YYYY-MM-DD`, when it was written) and a one-line summary.
- **Status:**
  - `Proposed`: written, not yet agreed.
  - `Accepted`: agreed; work is in progress or follows it.
  - `Done`: everything in it is implemented.
  - `Superseded`: replaced by a later plan; say which one in the header.
- Once a plan is accepted, leave its body alone. Update the status, or write a new plan that supersedes it.
